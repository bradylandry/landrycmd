01 · what I built

A review that used to take an hour, in three minutes

Firewall change requests were reviewed by hand across five disconnected systems — 30 to 60 minutes each, and easy to get wrong. I built an agent that runs the same eight checks every time: it traces the real path, pulls config for only the firewalls actually in it, and tests the request against the zone policy. It is read-only and always ends at a human.

Below: step through a request end to end. The scenario pills inject real failure modes I have hit — a firewall that does not exist, one that was decommissioned, a source address in a different routing domain — and the agent blocks instead of approving.
