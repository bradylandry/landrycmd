## Medium

### Path traversal via unchecked `providedSlug` in publish-note API
- **File**: `src/pages/api/publish-note.ts:70`
- **Issue**: The `providedSlug` field from the request body is accepted without any sanitization and concatenated directly into a GitHub file path: `` const filePath = `src/content/notes/${slug}.md` ``. An authenticated caller (possessing `PUBLISH_API_KEY`) can pass `../../middleware` as `providedSlug`, causing the GitHub API to write to `src/middleware.ts` instead. The GitHub Contents API normalizes `..` segments, so a crafted slug can overwrite arbitrary files in the repository.
- **Fix**: Apply `slugify()` to `providedSlug` as well as the title-derived slug, or validate with a strict pattern such as `/^[a-z0-9-]{1,100}$/` before use:
  ```ts
  const rawSlug = providedSlug ?? slugify(title);
  const slug = /^[a-z0-9-]{1,100}$/.test(rawSlug) ? rawSlug : slugify(title);
  ```

### YAML injection in `buildFrontmatter` for array elements containing double quotes
- **File**: `src/pages/api/publish-note.ts:22`
- **Issue**: Array values (e.g. `tags`) are serialized as `` `"${s}"` `` without escaping. A tag containing a double-quote character — e.g. `foo"bar` — produces `` tags: ["foo"bar"] ``, which is invalid YAML and will crash the Astro build. The single-quote branch (line 24) handles the string case, but the array branch has no equivalent guard.
- **Fix**: Escape double quotes inside array element strings, or switch to a simple replacement:
  ```ts
  lines.push(`${k}: [${v.map((s) => `"${s.replace(/"/g, '\\"')}"`).join(", ")}]`);
  ```

### Non-constant-time HMAC comparison in `verifyToken`
- **File**: `src/middleware.ts:25`
- **Issue**: Token verification uses JavaScript string equality (`expected !== sig`), which is not constant-time. In theory a timing side-channel could leak signature bytes. In practice, network jitter and the per-token changing payload (timestamps) make exploitation implausible for this app, but it's a pattern worth fixing before the codebase is reused in higher-stakes contexts.
- **Fix**: Use a timing-safe comparison:
  ```ts
  import { timingSafeEqual } from "node:crypto";
  // …
  const a = Buffer.from(expected);
  const b = Buffer.from(sig);
  if (a.length !== b.length || !timingSafeEqual(a, b)) return false;
  ```

### Missing `PUBLISH_API_KEY` and `GITHUB_TOKEN` declarations in `env.d.ts`
- **File**: `src/env.d.ts:1`
- **Issue**: `publish-note.ts` reads `import.meta.env.GITHUB_TOKEN` and `import.meta.env.PUBLISH_API_KEY`, but neither is declared in the `ImportMetaEnv` interface. TypeScript silently types them as `any`, missing typo protection and IDE autocomplete.
- **Fix**: Add to `env.d.ts`:
  ```ts
  readonly GITHUB_TOKEN: string;
  readonly PUBLISH_API_KEY: string;
  readonly GITHUB_REPO: string;
  ```
