## High

### Path traversal via `providedSlug` in publish-note API
- **File**: `src/pages/api/publish-note.ts:62`
- **Issue**: `providedSlug` from the request body is inserted directly into the GitHub API file path with no validation: `filePath = \`src/content/notes/${slug}.md\``. A value like `../../package` resolves to `src/package.md`, allowing writes outside the notes directory. GitHub normalizes the path server-side, so this is exploitable. Mitigated by `PUBLISH_API_KEY`, but a stolen key enables arbitrary repo file writes.
- **Fix**: Validate `providedSlug` against a strict allowlist (`/^[a-z0-9-]{1,100}$/`) before use, or strip path separators and reject slugs containing `/`, `\`, or `.` sequences.

## Medium

### `buildFrontmatter` produces invalid YAML for strings with mixed quotes
- **File**: `src/pages/api/publish-note.ts:23`
- **Issue**: The function wraps strings containing `"` in single quotes, but does not escape single quotes inside the value. A title like `Brady's "cool" post` produces `title: 'Brady's "cool" post'` — invalid YAML. This causes Astro's content collection build to fail and the note never appears on the site. Similarly, values containing newlines produce multi-line YAML that may break frontmatter delimiters.
- **Fix**: Use a YAML serialization library (e.g., `js-yaml`'s `dump()`) instead of hand-rolling frontmatter, or at minimum escape quotes inside values and strip/replace newlines.

### `getHits` called with `undefined` token for tokenless applications
- **File**: `src/pages/applications.astro:23`
- **Issue**: `APPLICATIONS.map(async (app) => { const hits = await getHits(app.token); ... })` iterates all applications including those without a `token` field (e.g. the RapidScale and Cisco entries). `app.token` is `string | undefined`; passing `undefined` queries Redis key `app:hits:undefined`, which always returns an empty array. Those applications will always show 0 hits even if data exists under a differently keyed entry. TypeScript should flag this under `strictNullChecks`.
- **Fix**: Guard the call: `const hits = app.token ? await getHits(app.token) : [];` TypeScript's strict mode would have caught this.
